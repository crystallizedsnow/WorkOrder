# 工单状态说明

## 状态码与含义

| 状态码 | 状态名称 | 含义说明 |
|--------|----------|----------|
| 100 | 未审核 | 工单已提交，等待审核 |
| 200 | 审核中 | 正在审核流程中 |
| 270 | 审核失败 | 审核未通过 |
| 300 | 未派单 | 审核通过，等待分配处理人 |
| 400 | 处理中 | 正在处理中 |
| 410 | 已超时 | 处理超时 |
| 500 | 已完成 | 处理完成，等待确认 |
| 600 | 已确认完成 | 确认通过，流程结束 |
| 670 | 确认失败 | 确认未通过 |
| 700 | 已取消 | 工单被取消 |

## 状态流转图

```
提交 → 未审核(100) → 审核中(200)
                        ├── 审核失败(270) → 返回修改
                        └── 未派单(300) → 处理中(400)
                                              ├── 已超时(410)
                                              ├── 已完成(500)
                                              │       ├── 确认失败(670) → 重新处理
                                              │       └── 已确认完成(600) → 流程结束
                                              └── 已取消(700) → 流程终止
```

## 各状态下一步操作建议

| 当前状态 | 下一步操作 | 说明 |
|----------|------------|------|
| 未审核(100) | 等待审核 | 等待审核人员处理 |
| 审核中(200) | 等待审核结果 | 审核人员正在审批 |
| 审核失败(270) | 修改后重新提交 | 根据审核意见修改工单 |
| 未派单(300) | 等待派单 | 等待分配处理人 |
| 处理中(400) | 等待处理完成 | 处理人员正在处理 |
| 已超时(410) | 联系处理人 | 提醒处理人员加快处理 |
| 已完成(500) | 等待确认 | 等待确认人确认结果 |
| 已确认完成(600) | 流程结束 | 工单已完成 |
| 确认失败(670) | 重新处理 | 根据确认意见重新处理 |
| 已取消(700) | 流程终止 | 工单已取消 |
