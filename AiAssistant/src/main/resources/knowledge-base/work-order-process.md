# 工单处理流程

## 流程概述

工单系统支持省市各部门发起维护工单申请，经过各层级审批，通过后提交到操作单位，操作人员执行后及时回单。

## 完整流程步骤

### 1. 创建工单
- 用户登录系统
- 填写工单信息（类型、标题、描述、优先级等）
- 提交工单

### 2. 审核流程
- 审核人收到工单通知
- 审核工单内容
- 审核通过 → 进入下一阶段
- 审核失败 → 返回修改

### 3. 派单流程
- 派单人分配处理人
- 可分配给单个或多个处理人
- 处理人收到派单通知

### 4. 处理流程
- 处理人接收工单
- 执行处理操作
- 填写处理结果
- 提交处理完成

### 5. 确认流程
- 确认人收到处理完成通知
- 确认处理结果
- 确认通过 → 流程结束
- 确认失败 → 重新处理

### 6. 取消流程
- 在任何阶段可取消工单
- 需要填写取消原因
- 取消后流程终止

## 核心能力

1. **工单查询** - 通过关键词搜索工单信息
2. **工单状态解释** - 解释不同工单状态的含义
3. **操作流程指导** - 指导用户完成工单的提交、审核、派单、处理、确认等操作
4. **统计报表** - 每日/每周工单流转完成情况统计
5. **超时预警** - 延时工单提醒

## 统计报表

### 每日统计
- 当日新增工单数
- 当日处理完成工单数
- 当日超时工单数

### 每周统计
- 本周新增工单数
- 本周处理完成工单数
- 本周各状态工单分布
- 本周各类型工单分布
- 本周各优先级工单分布

## 使用模式

- 电脑WEB门户
- 手机APP门户

## 权限控制

工单助手需要登录后才能使用，不同角色拥有不同的操作权限。
