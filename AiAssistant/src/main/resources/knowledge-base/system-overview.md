# 工单系统介绍

## 系统概述

工单系统支持省市各部门发起维护工单申请，经过各层级审批，通过后提交到操作单位，操作人员执行后及时回单。

## 功能模块

### 1. 工单查询
- 按工单编号、标题、关键词搜索
- 按状态、类型、优先级筛选
- 分页查询支持

### 2. 工单处理
- 工单创建与提交
- 审核流程管理
- 派单与分配
- 处理与回单
- 确认与完成

### 3. 工单导出
- 导出为Excel格式
- 导出为Markdown格式
- 自定义导出字段

### 4. 工单信息统计
- 每日工单流转完成情况统计
- 每周工单流转完成情况统计
- 各状态工单数量统计
- 各类型工单数量统计
- 各优先级工单数量统计

### 5. 延时工单提醒
- 超时预警通知
- 即将超时提醒
- 处理进度跟踪

### 6. 消息中心
- 工单审核通知
- 工单处理完成通知
- 系统通知
- 消息历史记录

### 7. 流程配置
- 审核流程配置
- 派单规则配置
- 处理时限配置
- 权限配置

### 8. 数据看板
- 工单统计概览
- 待办事项列表
- 状态统计图表
- 趋势分析

### 9. 用户权限控制
- 用户角色管理
- 权限分配
- 部门管理

## 用户角色

| 角色 | 权限 | 说明 |
|------|------|------|
| 省级管理员 | 全部权限 | 管理全省工单系统 |
| 市级管理员 | 市级权限 | 管理本市工单 |
| 普通用户 | 基础权限 | 创建、查看工单 |

## 使用模式

- 电脑WEB门户
- 手机APP门户

## 权限控制

工单助手需要登录后才能使用，不同角色拥有不同的操作权限。
