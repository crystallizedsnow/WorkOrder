# 工单类型说明

## 工单类型

| 类型码 | 类型名称 | 说明 |
|--------|----------|------|
| 0 | 需求类 | 用户提出的功能需求、改进建议等 |
| 1 | 故障类 | 系统故障、异常问题等 |

## 优先级说明

| 优先级码 | 优先级名称 | 说明 | 处理时限 |
|----------|------------|------|----------|
| 0 | 高优先级 | 需要立即处理的紧急事项 | 2小时内 |
| 1 | 中优先级 | 需要及时处理的常规事项 | 24小时内 |
| 2 | 低优先级 | 可延后处理的非紧急事项 | 48小时内 |

## 处理类型说明

| 处理类型码 | 处理类型名称 | 说明 |
|------------|--------------|------|
| 1 | 提交人 | 工单创建者 |
| 2 | 审核人 | 审核工单的人员（可以有多个，顺序审核） |
| 3 | 派单人 | 分配处理任务的人员 |
| 4 | 处理人 | 实际处理工单的人员（可以有多个，并行处理） |
| 5 | 确认人 | 确认处理结果的人员 |

## 优先级与处理时限关系

| 优先级 | 处理时限 | 超时预警 |
|--------|----------|----------|
| 高 | 2小时 | 处理开始后1.5小时 |
| 中 | 24小时 | 处理开始后20小时 |
| 低 | 48小时 | 处理开始后40小时 |

## 类型与优先级组合建议

| 工单类型 | 建议优先级 | 说明 |
|----------|------------|------|
| 故障类 | 高/中 | 根据故障影响范围确定 |
| 需求类 | 中/低 | 根据需求紧急程度确定 |
