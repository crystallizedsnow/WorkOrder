# 工单系统枚举数据

## 概述

本文档包含工单系统中的所有枚举类型定义，包括状态、类型、优先级和处理类型等。

---

## 1. 工单状态枚举

### 状态列表

| 状态码 | 状态名称 | 说明 |
|--------|----------|------|
| 100 | 未审核 | 工单已提交，等待审核人员审核 |
| 200 | 审核中 | 审核人员正在处理审核 |
| 270 | 审核失败 | 审核未通过，需要修改后重新提交 |
| 300 | 未派单 | 审核通过，等待分配处理人员 |
| 400 | 处理中 | 处理人员正在处理工单 |
| 410 | 已超时 | 处理时间超过预期，需要催单 |
| 500 | 已完成 | 处理人员完成处理，等待确认 |
| 600 | 已确认完成 | 确认通过，工单流程结束 |
| 670 | 确认失败 | 确认未通过，需要重新处理 |
| 700 | 已取消 | 工单被取消，流程终止 |

### 状态流转

```
未审核 (100)
    ↓
审核中 (200)
    ↓
┌─────┴─────┐
审核失败(270)  未派单 (300)
    ↓              ↓
重新提交        处理中 (400)
                    ↓
            ┌───────┴───────┐
            已超时(410)   已完成 (500)
                ↓              ↓
              催单      ┌───────┴───────┐
                    已确认完成(600)  确认失败(670)
                                          ↓
                                        重新处理
```

### 状态说明

- **未审核(100)**：工单刚创建，等待审核人员审核
- **审核中(200)**：审核人员正在查看和审核工单
- **审核失败(270)**：审核不通过，用户需要根据审核意见修改后重新提交
- **未派单(300)**：审核通过，等待管理员分配处理人员
- **处理中(400)**：工单已分配，处理人员正在处理
- **已超时(410)**：处理时间超过预期，需要催单提醒
- **已完成(500)**：处理人员完成工单，等待用户确认
- **已确认完成(600)**：用户确认满意，工单流程结束
- **确认失败(670)**：用户认为仍有问题，工单回到处理中
- **已取消(700)**：工单被取消，流程终止

---

## 2. 工单类型枚举

### 类型列表

| 类型码 | 类型名称 | 说明 |
|--------|----------|------|
| 0 | 需求 | 用户提出的需求类工单，如功能需求、改进建议等 |
| 1 | 故障 | 系统故障或问题报告类工单，如系统错误、服务异常等 |

### 类型说明

- **需求(0)**：用于提交新功能需求、改进建议、业务优化等请求
- **故障(1)**：用于报告系统故障、服务异常、数据错误等问题

---

## 3. 工单优先级枚举

### 优先级列表

| 优先级码 | 优先级名称 | 说明 |
|----------|------------|------|
| 0 | 高 | 高优先级，需要立即处理的紧急工单 |
| 1 | 中 | 中优先级，按正常流程处理 |
| 2 | 低 | 低优先级，可以延后处理 |

### 优先级说明

- **高(0)**：紧急工单，需要立即处理，影响业务正常运行
- **中(1)**：普通工单，按正常工作流程处理
- **低(2)**：次要工单，可以在空闲时间处理

---

## 4. 处理类型枚举

### 处理类型列表

| 类型码 | 类型名称 | 说明 |
|--------|----------|------|
| 1 | 分配 | 将工单分配给处理人员 |
| 2 | 请求协助 | 处理人员请求其他人员协助 |
| 3 | 催单 | 对超时工单进行催单提醒 |
| 4 | 完成 | 处理人员完成工单处理 |
| 5 | 确认完成 | 用户确认工单处理结果满意 |
| 6 | 仍有问题 | 用户认为工单仍有问题，需要重新处理 |
| 7 | 创建成功 | 工单创建成功 |
| 8 | 审核 | 审核人员对工单进行审核 |

### 处理类型说明

- **分配(1)**：管理员将工单分配给具体处理人员
- **请求协助(2)**：处理人员遇到困难，请求其他人员协助处理
- **催单(3)**：对超时工单进行催单，提醒处理人员加快处理
- **完成(4)**：处理人员完成工单的处理工作
- **确认完成(5)**：用户确认工单处理结果，流程结束
- **仍有问题(6)**：用户认为工单仍有问题，返回重新处理
- **创建成功(7)**：工单创建成功的记录
- **审核(8)**：审核人员对工单进行审核操作
